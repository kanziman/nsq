# 오디오 파형 시각화 + 세밀한 재생 속도 조절 — 확정 요구사항

## 용어 정의 (Ubiquitous Language)

| 용어                            | 정의                                                                                            |
| ------------------------------- | ----------------------------------------------------------------------------------------------- |
| **파형(Waveform)**              | 오디오 신호의 진폭을 세로 바(bar) 형태로 시각화한 UI 요소                                       |
| **세그먼트 파형**               | 현재 재생 중인 세그먼트(문장) 범위의 파형. 세그먼트 전환 시 갱신됨                              |
| **속도 슬라이더(Speed Slider)** | 0.05 단위로 재생 속도를 조절하는 range input + ±스텝 버튼 복합 컨트롤                           |
| **프리셋 버튼**                 | 기존 고정 속도 선택 버튼 (`[0.5, 0.75, 1, 1.25, 1.5, 2]`). 이번 작업에서 속도 슬라이더로 교체됨 |
| **바(Bar)**                     | 파형을 구성하는 개별 세로 막대                                                                  |
| **에피소드 보드**               | 에피소드 목록 페이지(`/`). 플레이어에서 복귀하는 대상                                           |

---

## 1. 오디오 파형 시각화

### 1-1. 표시 범위

- **현재 세그먼트(문장) 단위**의 파형만 표시한다.
- 세그먼트가 전환되면 해당 세그먼트 구간의 파형으로 갱신한다.
- 세그먼트가 없는 상태(`currentSegmentIndex < 0`)에서는 빈 파형(flat bar)을 표시한다.

### 1-2. 파형 데이터 생성

- **Web Audio API (`AudioContext.decodeAudioData`)** 를 사용해 클라이언트에서 실시간 디코딩한다.
- 에피소드 오디오 로드 시 1회 전체 디코딩 → `AudioBuffer` 캐시.
- 세그먼트 전환 시 `AudioBuffer`에서 해당 구간의 PCM 샘플을 추출해 바 높이 배열로 변환한다.
- 외부 라이브러리(wavesurfer.js 등)는 사용하지 않는다.

### 1-3. UI 배치

- **기존 타임라인 시크바(1단)는 유지**한다.
- 파형은 시크바 **아래**, 재생 버튼(2단) **위**에 새로운 영역으로 추가한다.
- 파형 영역 높이: 약 48~64px.

### 1-4. 파형 상호작용

- 파형 클릭 시 세그먼트 내 해당 시간 위치로 seek 이동한다.
- 재생 진행에 따라 재생된 바는 `primary` 색상, 미재생 바는 `surface-dark-soft` 색상으로 구분한다.
- 현재 재생 위치를 시각적으로 표시한다(바 색상 전환 또는 플레이헤드).

### 1-5. 시각 디자인

- **바(Bar) 형태**: 세로 바를 나란히 배치.
- 바 개수: 컨테이너 너비에 따라 동적 계산 (바 너비 2~3px + 간격 1px 기준).
- 재생 완료 바: `primary` 색상.
- 미재생 바: `surface-dark-soft` 색상.
- 배경: `surface-dark` (기존 플레이어 영역과 일치).
- 반올림 모서리(rounded top).

## 2. 재생 속도 조절 개선

### 2-1. 조절 방식

- 기존 프리셋 버튼 6개(`[0.5, 0.75, 1, 1.25, 1.5, 2]`)를 **슬라이더 + ±스텝 버튼**으로 교체한다.
- **범위**: 0.50x ~ 2.00x.
- **스텝 단위**: 0.05.
- **구성 요소**:
  - 상단: 현재 속도 수치 표시 (예: `1.00x`)
  - 중앙: range input 슬라이더
  - 좌측: `-` 버튼 (0.05 감속)
  - 우측: `+` 버튼 (0.05 가속)

### 2-2. 1x 리셋

- 속도 수치 텍스트(`1.00x`) 클릭 시 **1.0x로 초기화**.
- 슬라이더 더블클릭 시에도 **1.0x 리셋**.

### 2-3. 키보드 단축키

- 기존 `+`/`-` 키보드 단축키는 유지하되, 스텝 단위를 **0.05**로 변경한다.
- `PLAYBACK_RATE_PRESETS` 기반 인덱스 스텝 대신 현재 속도에서 ±0.05 산술 연산으로 변경.

## 3. 경계 조건 및 에러 처리

| 조건                              | 동작                                                         |
| --------------------------------- | ------------------------------------------------------------ |
| Web Audio API 미지원 브라우저     | 파형 영역을 숨기고 기존 시크바만 표시 (graceful degradation) |
| AudioBuffer 디코딩 실패           | 콘솔 경고, 파형 영역 숨김, 재생 기능에는 영향 없음           |
| 세그먼트 길이 0 또는 매우 짧음    | 최소 바 1개 이상 표시                                        |
| 속도 범위 초과 (< 0.5 또는 > 2.0) | 클램핑 (min/max에서 정지)                                    |
| 에피소드 전환 시                  | AudioBuffer 캐시 해제 → 새 에피소드 디코딩                   |

---

## 4. 성능 제약

- AudioBuffer 디코딩은 에피소드 최초 로드 시 1회만 수행. 이후 메모리에 캐시.
- 파형 바 높이 계산은 세그먼트 전환 시 1회. `useMemo`로 재계산 방지.
- Canvas 대신 **div + CSS** 또는 **SVG**로 렌더링해 React 친화적 구현 유지 (바 개수가 적당하므로 DOM 성능 문제 없음).
- 재생 진행에 따른 바 색상 갱신은 `requestAnimationFrame` 또는 `timeupdate` 이벤트로.

---

## 5. 확장성

- 향후 전체 에피소드 파형 뷰 추가 시 동일한 파형 데이터 유틸리티 재사용 가능하도록 분리.
- 속도 프리셋 퀵 버튼(0.5x, 1x, 1.5x 등)은 Out of Scope이나, 슬라이더 옆에 쉽게 추가 가능한 구조 유지.

---

## 6. 에피소드 보드 복귀 버튼

### 6-1. 동작

- 플레이어 상단에 에피소드 목록 페이지(`/`)로 돌아가는 **뒤로가기 버튼**을 배치한다.
- 클릭 시 `router.push('/')` 또는 `<Link href="/">` 로 에피소드 보드로 이동.

### 6-2. UI

- 에피소드 제목(`<h2>`) 좌측에 ← 아이콘(ArrowLeft 또는 ChevronLeft) 버튼.
- 다크 배경 플레이어 영역 내에 위치하므로 `secondaryOnDark` variant 적용.
- 아이콘만 표시 (텍스트 없음), `aria-label="에피소드 목록으로"`.

### 6-3. 경계 조건

- 재생 중 클릭 시에도 즉시 이동 (오디오는 페이지 전환으로 자동 정리됨).

## 7. CJK Serif 폰트 폴백

### 7-1. 문제

- 현재 `--font-serif`가 `'Cormorant Garamond', Garamond, Times New Roman, serif`로 Latin 전용.
- 일본어 에피소드 제목(`英語の単語は借り物だらけ`)이나 AI Tutor 헤더 등 serif가 적용되는 CJK 텍스트는 시스템 기본 serif로 폴백되어 의도한 디자인과 불일치.

### 7-2. 변경

- `globals.css`의 `--font-serif` 폰트 스택에 **CJK serif 폰트**를 추가한다.
- 폰트 순서: `'Cormorant Garamond', 'Noto Serif JP', 'Yu Mincho', Garamond, 'Times New Roman', serif`
- `Noto Serif JP`는 Google Fonts에서 로드(weight 400, 700).
- 일본어 외에도 한국어 에피소드 제목을 위해 `'Noto Serif KR'` 추가도 고려하되, 이번 MVP는 ja만 대상.

### 7-3. 적용 범위

- 에피소드 제목(`<h2 class="font-serif">`)
- AI Tutor 헤더(`<h2 class="font-serif">`)
- 기타 `font-serif`를 사용하는 모든 CJK 텍스트
