# 오디오 파형 시각화 + 세밀한 재생 속도 조절

## 초기 아이디어

### 1. 오디오 파형 시각화 (Waveform Visualization)

- 현재 재생 구간의 오디오 파형을 시각적으로 표시한다.
- 파형 클릭으로 해당 위치로 탐색(seek) 이동 가능.
- checklist.json `player-waveform` 항목에 해당.

### 2. 재생 속도 조절 개선 (Playback Rate Control)

- 현재: 프리셋 버튼 6개 (`[0.5, 0.75, 1, 1.25, 1.5, 2]`) 중 선택하는 방식.
- 변경: **0.05 단위**로 세밀하게 조절 가능한 **슬라이더 + ±스텝 버튼** UI.
  - 범위: 0.5x ~ 2.0x
  - 슬라이더로 연속 조절
  - ±버튼으로 0.05 단위 스텝 조절
  - 현재 속도를 수치로 표시 (예: `1.00x`)
- 사용자가 보여준 레퍼런스 이미지: 다크 배경 위 슬라이더 + 양쪽 - / + 버튼, 상단 속도 텍스트.
