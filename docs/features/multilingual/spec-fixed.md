# multilingual — 확정 요구사항 (spec-fixed)

> `spec-original.md` + 코드베이스 분석 + Stage 1 인터뷰(추천안 자동 확정 정책)로 확정.
> **[GATE 1] 통과** — 사용자 상시 정책("승인 게이트는 추천안대로 자동 진행")에 따라 추천안으로 확정. veto 시 본 문서 수정 후 하위 단계 재생성.

## 1. 한 줄 정의

공식 대본(transcriptUrl)이 없는 유튜브 영상을 **자동 자막(VTT)만으로 임포트**하는 "자막 전용(subtitle-only) 모드"를 추가하고, 에피소드에 **언어 속성(`language: 'en' | 'ja'`)**을 도입해 문장 복원·번역·단어 하이라이트·후리가나·튜터를 언어별로 분기한다. 우선 타깃은 **일본어** 학습 콘텐츠.

## 2. 핵심 사용자 (Primary User)

- **직접 사용자**: 에피소드를 임포트해 쉐도잉하는 학습자 본인(관리자 1인 로컬 워크플로우, 기존과 동일).
- **가치**: Freakonomics처럼 공식 대본이 있는 소스가 아니어도(일본어 팟캐스트·인터뷰 영상 등) URL 하나로 임포트해, 기존 플레이어·스크립트 뷰·번역·튜터를 그대로 활용한 일본어 쉐도잉 학습이 가능해진다.

## 5. 최소 동작 시나리오 (3)

1. **일본어 영상 임포트**: 임포트 폼에서 언어 `ja` 선택, 대본 URL 비움 → 접수 → 오디오 다운로드 + `subtitle.ja.vtt`(자동 자막 폴백) → LLM 문장 복원으로 문장 단위 `segments.json` → ja→ko 번역 주입 → completed. 에피소드 목록에 카드 등장.
2. **일본어 쉐도잉 학습**: ja 에피소드 열기 → 한자 위 후리가나(`<ruby>`) 표시(토글 가능), 재생 중 현재 단어 하이라이트(Intl.Segmenter 분해), 단어 클릭 시 네이버 일본어사전 새 탭. 번역 blur/토글은 기존 그대로.
3. **문장 복원 실패 완주**: LLM 전면 오류 → 큐 단위 세그먼트로 completed(재생·학습 가능) → 이후 `retryStep: 'sentences'`로 문장 복원만 재실행해 업그레이드.

## 6. 경계 조건

- **자막 자체가 없는 영상**(수동·자동 모두): subtitle 단계 실패 → `failed`(기존 에러 경로 재사용).
- **대본 URL이 있는 기존(en) 임포트**: 완전 무변경 경로(회귀 0). `language` 미지정 시 `'en'`.
- **ja 선택 + 대본 URL 입력**: 허용하지 않음(폼에서 대본 URL은 en에서만 노출). 파이프라인 조합 폭발 방지.
- **문장 복원 응답의 큐 인덱스 불일치**(범위 밖·중복·누락): 해당 배치 스킵(그 구간은 큐 단위 유지), best-effort.
- **루비 검증 실패**(`join(text) !== segment.text`): 해당 세그먼트 루비 미표시, 원문 그대로.
- **`Intl.Segmenter` 미지원 브라우저**: 세그먼트 전체를 단일 토큰으로 폴백(하이라이트 문장 단위 강등, 크래시 없음).
- **기존 에피소드(segments.json에 ruby 없음)**: 옵셔널 필드라 무영향.

## 7. 예외 및 에러 처리 (UI 전달)

- **필수 단계**(download, subtitle): 실패 시 기존과 동일하게 `failed` + 모니터 에러 + 재시도 버튼.
- **best-effort 단계**(sentence-builder, translation, furigana): 실패해도 completed. 모니터에는 진행 상태만 표시(translation 정책과 동일).
- 문장 복원 실패로 큐 단위 세그먼트인 경우에도 사용자 에러로 노출하지 않음(서버 로그 기록).

## 8. 성능 제약

- 문장 복원: 큐 N개 → 약 `ceil(N/60)`회 LLM 호출. 후리가나: 세그먼트 M개 → 약 `ceil(M/20)`회. 모두 fire-and-forget 파이프라인 내부라 사용자 폴링 UX는 기존과 동일.
- `Intl.Segmenter` 분해는 세그먼트 단위 메모이제이션(재생 틱마다 재분해 금지).

## 9. 기존 UI/패턴 일관성

- 임포트 폼: 기존 Input/Button 컴포넌트 + 언어는 기존 모드 버튼 패턴(플레이어 모드 선택과 동일한 세그먼티드 버튼) 재사용.
- 후리가나·번역 토글: 컨트롤 헤더 배치(#114 패턴).
- 스텝 모듈: `src/lib/services/import/sentence-builder.ts`, `furigana.ts` — `translation.ts`와 동일한 DI(주입형 LLM 호출)·배치·증분 저장·로깅 컨벤션.

## 10. 향후 확장성 / 종속성

- **선행**: import 파이프라인(완료), translation 스텝(완료), 동적 화자 튜터(#121, 완료).
- **확장 여지(범위 밖)**: zh 등 언어 추가(union 확장), Whisper ASR(자막 없는 영상), 화자 분리(diarization), 인앱 사전 팝업(learning-dictionary), pitch accent 표시.

## 11. 용어 정의 (Ubiquitous Language)

| 용어                                   | 정의                                                                                                             |
| :------------------------------------- | :--------------------------------------------------------------------------------------------------------------- |
| **자막 전용 모드(subtitle-only mode)** | transcriptUrl 없이 자동/수동 자막 VTT만으로 segments.json을 생성하는 임포트 경로. 정합(alignment)·matchRate 없음 |
| **대본 정합 모드(transcript mode)**    | 기존 경로. transcriptUrl 필수, alignment + matchRate ≥ 0.85 게이트                                               |
| **language**                           | `EpisodeMeta.language?: 'en' \| 'ja'`. 부재 시 `'en'`. 번역·표시·튜터 분기의 단일 기준                           |
| **문장 복원(sentence-builder)**        | 파편화된 VTT 큐들을 LLM으로 자연 문장 단위로 병합·구두점 복원해 segments.json을 재구성하는 스텝. best-effort     |
| **큐 세그먼트(cue segment)**           | 문장 복원 이전/실패 시의 폴백 산출 — VTT 큐 1개 = 세그먼트 1개                                                   |
| **루비(ruby)**                         | `Segment.ruby` 토큰 시퀀스. 한자 표기(text) + 요미가나(rt). `<ruby>` 렌더의 데이터 원천                          |
| **토큰(token, ja)**                    | `Intl.Segmenter`가 분해한 일본어 단어 단위. 하이라이트·사전 클릭의 단위                                          |
